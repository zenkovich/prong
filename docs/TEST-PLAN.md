# Prong — план тестирования

Три уровня, все запускаются без окон и без доступа к `~/.prong` и настоящим репозиториям пользователя:

| Уровень | Команда | Что проверяет | Где |
|---|---|---|---|
| Движок (unit + интеграция с git) | `npm run server:test` | парсеры, операции над настоящими временными репозиториями, медиа и Range, политика Origin, иконки ОС, HTTP API + SSE, сервисы | `server/test/*.test.ts` |
| Приложение (unit) | `npm test` | стор, live-слой (с подменённым клиентом), граф, агент (маршрутизация, статус, уведомления, стоп), вкладки, геометрия медиа, иконки, границы ошибок | `src/**/*.test.ts` |
| Сквозные (e2e) | `npm run e2e` | экспортированный web UI против настоящего движка в headless Chromium | `tools/e2e.mjs` |
| Всё вместе | `npm run test:all` | typecheck + три уровня | |

E2E требует web-экспорта (`macos/build.sh` или `npx expo export --platform web --output-dir macos/build/web`); движок компилируется сам перед прогоном (`pree2e`). Движок стартует на случайном порту с временной папкой состояния; фикстурные репозитории создаются во временной папке и удаляются после прогона. Агент — заглушка `tools/fake-claude.sh` (печатает события stream-json; «slow» ждёт 30 с для проверки стопа, «edit-ui» правит файл исходников). Сборка интерфейса — `tools/fake-ui-build.sh` через `PRONG_UI_BUILD_CMD` (копия заводской сборки с меткой; BREAK в исходниках — ошибка сборки). Медиа-фикстуры: PNG собираются в харнессе, WAV синтезируется, видео — `tools/fixtures/*.webm` и неподдерживаемый `legacy.avi`. `E2E_SHOTS=<папка>` сохраняет скриншот после каждой проверки.

## Что не покрыто автоматически

- Нативная оболочка macOS (WKWebView, выбор папки, открытие ссылок): проверяется вручную запуском Prong.app. Воспроизведение видео в WebKit (Range-ответы движка проверены тестами, сам плеер — нет) и настоящий жест pinch на тачпаде проверяются там же.
- Системные иконки Windows и Linux: проверены только чистые части (скрипт PowerShell, разбор gio, поиск в теме); живой рендер — только macOS.
- Реальные сетевые сервисы (GitHub device flow, Gravatar): тесты используют подменённые fetch и 404-ответы.
- Прогон Claude Code: только маршрутизация и маркер; живой запуск стоит денег и проверяется вручную.
